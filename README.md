# Classic Bags Co. Website

A professional single-page website for Classic Bags Co., a family-run bag business offering quality bags and custom designs.

## Deployment

This website is configured for automatic deployment using GitHub Pages.

### Setup Instructions

1. Go to repository Settings → Pages
2. Under "Build and deployment":
   - Source: Select "GitHub Actions"
3. The site will automatically deploy when changes are pushed to the `main` or `copilot/deploy-app-to-production` branch

### Manual Deployment

You can trigger a manual deployment by:
- Going to Actions tab
- Selecting "Deploy Classic Bags Website"
- Clicking "Run workflow"
