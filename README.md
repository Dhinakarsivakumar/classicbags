# Classic Bags Co. Static Site

A single-page, mobile-first portfolio website for a family-run bag business. Built with HTML, CSS, and minimal JavaScript so it can be deployed on any static host.

## Deploy

### GitHub Pages
1. Commit the files to your repository.
2. In GitHub, go to **Settings → Pages**.
3. Select **Deploy from a branch**, choose the default branch, and set the root folder to `/`.
4. Save and wait for the Pages URL to appear.

### Netlify
1. Drag-and-drop the project folder into Netlify **Deploy**.
2. Or connect a Git repository and select the default branch.
3. Build command: *(none)*, Publish directory: `/`.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
